## ⚙️ Как настроить за 1 минуту прямо в Визуальном редакторе (UI блоки)

Все примеры построены так, чтобы после вставки в *«Изменить в YAML»* и переключения обратно в **«Визуальный редактор»** каждый шаг отображался **понятными визуальными карточками Home Assistant** (без серых YAML-блоков):

1. **В триггере `Событие`** замените `peer_id: 2000000003` на ID вашей беседы/диалога ВК (или укажите свои `user_id` в условии для Telegram).
2. **В действиях `VK Notify` / `Telegram`** просто выберите мышкой из выпадающего списка вашу сущность чата (`notify.vk_notify_...` или `notify.telegram_bot_...`).
3. **В действии `Диалоговая система: Обработать`** выберите мышкой вашего агента Yandex AI (рекомендуется создать отдельного второго агента кнопкой `+ Добавить диалоговую систему` специально для мессенджеров).
4. *(Если чат ВК личный, а не групповая беседа)* — в блоке **«И если (Conditions)»** можно одним кликом отключить условие проверки слова `бот190`, чтобы общаться живым диалогом без имени!

## 🔍 Требования к модели и настройке `Conversation` для Vision и Поиска по картинке

В настройках диалогового агента ⚙️ текстовый поиск и поиск по картинке **разделены на два независимых переключателя**:

1. **Права сервисного аккаунта в Yandex Cloud:** для работы и текстового поиска, и поиска по картинке у сервисного аккаунта должна быть назначена роль **`search-api.webSearch.user`** (и скоуп `yc.search-api.execute`, если вы ограничивали области действия ключа вручную — либо создайте ключ в 1 клик на [aistudio.yandex.ru](https://aistudio.yandex.ru/)).
2. **Какую модель выбрать в настройках `Conversation` для Поиска по картинке (`image_search`):**
   - Для одновременного просмотра фотографии (`Vision`) и вызова поискового инструмента (`yandex_image_search`) нужна мультимодальная модель с поддержкой **Function Calling (`tools`)**.
   - **Рекомендуемая модель:** **`Qwen3.6 35B Vision` (`qwen3.6-35b-a3b/latest`)** (отключите *«Рекомендуемые настройки модели»* и выберите её в списке, либо используйте `deepseek-v4.1-flash/latest`).
   - **Автоматическая подстановка Vision-модели:** если в агенте оставлены *«Рекомендуемые настройки модели = Вкл»* (`yandexgpt-5.1/latest`) или выбрана текстовая модель (`aliceai-llm-flash/latest`, `aliceai-llm/latest`), то на сообщении с тегом `[image: ...]` интеграция **автоматически** переключит запрос на **`qwen3.6-35b-a3b/latest`**.
   - ⚠️ **Не выбирайте устаревшую модель `Gemma 3 27B Vision` (`gemma-3-27b-it/latest`)**, если включён Поиск по картинке, Поиск в интернете или `AI tools` — `Gemma 3` не поддерживает вызов инструментов (`tools`) в API Yandex AI Studio.
3. **Разграничение приватности и расходов при работе с фото:**
   - **Только «Глаза ИИ» без отправки фото в поисковик (`Поиск по картинке = Выкл`, по умолчанию):** присланные фотографии (счётчики, чеки, квитанции, ошибки на экране) читаются и анализируются **только мультимодальной моделью `Qwen3.6 35B Vision`** — инструмент `yandex_image_search` отключён (`0 ₽` за поиск).
   - **Режим «Умной камеры Яндекса» (`Поиск по картинке = Вкл`):** модель получает доступ к обратному поиску по изображению (`POST /v2/image/search_by_image` CBIR, `0.915 ₽` при срабатывании) и при вопросах *«что это за растение / деталь / кроссовки и где купить?»* возвращает точные названия, карточки товаров и ссылки на сайты.
   - **Дополнительные ограничения:** если вы не хотите принимать фотографии в чат-боте — удалите переменную `photo_tags` из `vk_chatbot.yaml` (или триггер `telegram_attachment` из `telegram_chatbot.yaml`), а в системном промпте можно ограничить поиск конкретным доменом (`site: "market.yandex.ru"` или `"wikipedia.org"`).
