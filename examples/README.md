# 📂 Готовые примеры автоматизаций (Automation Examples)

В этой папке собраны готовые, проверенные на **Home Assistant 2025.8+ / 2026.x** файлы автоматизаций (вы можете открыть любой `.yaml` в режиме `Raw` и вставить в редактор автоматизаций Home Assistant в режиме *«Изменить в YAML»*).

## Список файлов

| Файл | Назначение |
| :--- | :--- |
| **[`vk_chatbot.yaml`](vk_chatbot.yaml)** | Умный чат-бот для **ВКонтакте** (через интеграцию [VK Notify](https://github.com/Eugen417/ha_vk_notify_plus)): живой диалог без префикса в личных сообщениях (`peer_id < 2000000000`) и активация по имени **`Бот190` / `бот 190`** в групповых беседах. Поддерживает текст, голосовые сообщения (`transcript`) и приём фотографий (`[image: <url>]`). |
| **[`vk_camera_vision.yaml`](vk_camera_vision.yaml)** | Команда **`/камера`** во ВКонтакте: снимает кадр с камеры `camera.*`, анализирует обстановку через `Qwen3.6 35B Vision` (`ai_task.generate_data`) и присылает фото с готовым текстовым отчётом. |
| **[`telegram_chatbot.yaml`](telegram_chatbot.yaml)** | Умный чат-бот для **Telegram** (штатная интеграция `telegram_bot`, схема HA 2026+ с `chat_id`): живой диалог в ЛС + активация по имени **`Бот190`** в группах, приём текста и фотографий (`telegram_bot.download_file`), индикатор `typing` и ответ цитатой. |
| **[`ai_task_examples.yaml`](ai_task_examples.yaml)** | Примеры шагов `ai_task.generate_image` (*Alice AI ART 3.0*) и `ai_task.generate_data` (текстовая сводка и анализ камеры *Qwen3.6 Vision*). |

## ⚙️ Как настроить за 1 минуту прямо в Визуальном редакторе (UI блоки)

Все примеры построены так, чтобы после вставки в *«Изменить в YAML»* и переключения обратно в **«Визуальный редактор»** каждый шаг отображался **понятными визуальными карточками Home Assistant** (без серых YAML-блоков):

1. **В триггере `Событие`** замените `peer_id: 2000000003` на ID вашей беседы или личного диалога ВК.
2. **В действиях `VK Notify` / `Telegram`** просто выберите мышкой из выпадающего списка вашу сущность чата (`notify.vk_notify_...` или `notify.telegram_bot_...`).
3. **В действии `Диалоговая система: Обработать`** выберите мышкой вашего агента Yandex AI (например, `Yandex AI Conversation` или созданного отдельного агента для чата).
4. *(Если чат личный, а не групповая беседа)* — в блоке **«И если (Conditions)»** можно одним кликом отключить условие проверки слова `бот190`, чтобы общаться живым диалогом без имени!

## 🔒 Как гибко управлять работой с фотографиями и Поиском по картинке

В настройках диалогового агента текстовый поиск и поиск по картинке **разделены на два независимых переключателя**:

1. **Только «Глаза ИИ» без отправки фото в поисковик (`Поиск по картинке = Выкл`, по умолчанию):**
   присланные в чат фотографии (счётчики, чеки, квитанции, ошибки на экране) читаются и анализируются **только мультимодальной моделью `Qwen3.6 35B Vision`** — инструмент `yandex_image_search` отключён и лишние запросы в Яндекс Картинки (`0.915 ₽`) не выполняются.
2. **Режим «Умной камеры Яндекса» (`Поиск по картинке = Вкл`):**
   модель получает доступ к обратному поиску по изображению (`POST /v2/image/search_by_image` CBIR) и при вопросах *«что это за растение / деталь / кроссовки и где купить?»* возвращает точные карточки товаров и ссылки на сайты.
3. **Ограничение на стороне самой автоматизации или промпта:**
   - если вы вообще не хотите принимать фотографии в чат-боте — просто удалите переменную `photo_tags` из `vk_chatbot.yaml` (или триггер `telegram_attachment` из `telegram_chatbot.yaml`);
   - в системном промпте агента можно дополнительно ограничить вызов `yandex_image_search` конкретным доменом (`site: "market.yandex.ru"` или `"wikipedia.org"`).
